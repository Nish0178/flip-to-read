🛡️ Privacy & Data Ethics

Flip to Read is built with a strict privacy-first foundation:

  • No Background Surveillance: The extension does not monitor, record, or transmit your browsing history or visited URLs.
  • No Silent Uploads: PDFs are NEVER uploaded or processed automatically without your explicit action ("Open as Flipbook" or "Upload Local PDF").
  • Local Storage Only: Reading bookmarks are stored securely inside your browser's chrome.storage.local.
  • Minimal Permissions: Only strictly required browser capabilities (storage, activeTab, tabs, contextMenus) are used.

About Flip to Read

Flip to Read is an open-source, full-stack PDF flipbook platform engineered with Java 21, Spring Boot, PyMuPDF, PageFlip, and Chrome Manifest V3. It transforms static documents into interactive 3D books with realistic physics-based page flips, zero scrolling, and single-file offline standalone downloads.

Version 1.0.0 • Architecture: Spring Boot API + Chrome/Edge Extension + PyMuPDF Service
